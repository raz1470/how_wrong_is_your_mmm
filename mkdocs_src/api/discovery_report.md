# DiscoveryReport

Sweeps candidate phasing strategies (or pins one directly, with per-channel
overrides) and packages `CollinearityDiagnostic` + `IdentifiabilityDiagnostic`
output into a single, client-ready HTML report — the impact on variance,
bias and identifiability, and the recommended weekly schedule as an
exportable CSV. No code required to read it.

::: how_wrong_is_your_mmm.DiscoveryReport
